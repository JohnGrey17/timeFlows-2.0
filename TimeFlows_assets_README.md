# TimeFlows --- анотація графічних файлів

Цей файл пояснює призначення кожного PNG-елемента з архіву
`timeflows_assets.zip` і куди його використовувати в інтерфейсі.

## Брендинг та favicon

### `logo_timeFlows.png`

Основний логотип **timeFlows**: знак годинника + текст `timeFlows`.

**Куди вставляти:** у верхню частину лівого Sidebar замість поточного
текстового логотипа.

### `icon_32px_orange.png`

Помаранчевий знак TimeFlows у збільшеному варіанті.

**Куди вставляти:** як окрему іконку бренду там, де використовується
світла/помаранчева тема. Може використовуватися як app icon або великий
варіант favicon.

### `icon_16px_orange.png`

Компактний помаранчевий знак TimeFlows.

**Куди вставляти:** favicon браузера або інші дуже маленькі місця
інтерфейсу у помаранчевій темі.

### `icon_32px_gradient.png`

Квадратна брендова іконка TimeFlows із бірюзово-синьо-фіолетовим
градієнтом.

**Куди вставляти:** основна app icon / PWA icon / ярлик застосунку.
Також можна використовувати у великих розмірах у браузері чи меню
застосунку.

### `icon_16px_gradient.png`

Компактна версія градієнтної іконки TimeFlows.

**Куди вставляти:** рекомендований favicon для вкладки браузера. Саме
цей файл найбільше підходить для маленького значка біля назви вкладки
TimeFlows.

## Готові пункти Sidebar

Наступні файли вже містять іконку разом із текстом. Їх варто
використовувати тільки якщо пункт меню вставляється як готове
зображення. Якщо меню реалізоване через HTML/CSS, краще використовувати
окремі `icon_*.png`.

### `nav_over_time_active.png`

Повний активний пункт **Over time** з фоном та помаранчевою іконкою.

**Куди вставляти:** Sidebar, коли користувач знаходиться на сторінці
Over time. Це активний стан пункту меню.

### `nav_item_over_time.png`

Іконка + напис **Over time** без повного активного контейнера.

**Куди вставляти:** звичайний/неактивний пункт Over time у Sidebar або
як графічний референс для верстки.

### `nav_item_overtime_check.png`

Іконка + напис **«Перевірка overtime»**.

### `nav_item_departments.png`

Іконка + напис **«Керування відділами»**.

**Куди вставляти:** відповідний пункт Sidebar, якщо він використовується

## Рекомендований варіант реалізації

Для самого вебзастосунку бажано не вставляти весь Sidebar готовими
картинками. Оптимальна структура:

-   `logo_timeFlows.png` → логотип угорі Sidebar.
-   `icon_16px_gradient.png` → favicon вкладки браузера.
-   `icon_settings.png` → Налаштування.
-   `icon_users.png` → Користувачі.
-   `icon_overtime_check.png` → Перевірка overtime.
-   `icon_departments.png` → Керування відділами.
-   Для **Over time** використати часову іконку з брендингу, а активний
    фон пункту зробити через CSS.

Файли `nav_item_*.png` та `nav_over_time_active.png` краще
використовувати як **референс дизайну**, а не як основні UI-компоненти.
Так текст залишатиметься чітким при масштабуванні, а hover/active стани
можна буде нормально реалізувати через CSS.
